# Minimal Clothing — Mobile Commerce

This repository is prepared for development with **OpenAI Codex**. It contains a persistent engineering contract and a prioritized implementation plan. The app itself has **not** been built yet.

## How to start a Codex task
1. Open Codex (app or web), connect your GitHub account if prompted, and select `tuyenbui99er-design/Langding-page`.
2. Start a new task with the following message:

> Đọc AGENTS.md, GOALS.md, TASKS.md và PLANS.md. Hãy tự triển khai Phase 0, tạo ứng dụng hoạt động thực tế, kiểm thử trên các kích thước di động 320/360/390/430px, chạy lint/typecheck/build, sửa lỗi và cập nhật tiến độ. Làm việc trên branch riêng và gửi pull request để tôi duyệt. Không triển khai production hay sử dụng dữ liệu/đánh giá giả.

3. Review tests, changed files, and proposed pull request before merging.

## Repository guide
- `AGENTS.md` — Persistent behavior, engineering standards and safety boundaries for Codex.
- `GOALS.md` — Product specification and commercial rules.
- `TASKS.md` — Development backlog with acceptance criteria.
- `PLANS.md` — Working plan and actual verification log.
